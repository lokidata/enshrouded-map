# Code of conduct

Be respectful. Disagree with ideas, not with people. No harassment, discrimination, personal attacks, or publishing someone's private information.

The maintainer may remove comments, issues or pull requests that break these rules, and block repeat offenders. To report a problem, contact the maintainer through their GitHub profile ([@lokidata](https://github.com/lokidata)).

This is a short adaptation of the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
